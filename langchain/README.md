# LangChain Basics 🚀

This folder contains basic implementations of LangChain concepts and NLP concepts.

## Files

* 01_llm_basic.py → Simple LLM call
* 02_prompt_template.py → Prompt engineering
* 03_simple_qa.py → Interactive Q&A
* 04_chat_memory.py → Chat with memory

## Setup

1. Install dependencies:

```bash
pip install langchain langchain-openai openai python-dotenv
```

2. Set your API key:

```bash
export OPENAI_API_KEY="your_api_key"
```

(Windows)

```bash
set OPENAI_API_KEY=your_api_key
```
